# fART - Digital Art Gallery

A modern, responsive Jekyll-based gallery for showcasing digital artwork with a clean, professional design.

## Features

- **Responsive Grid Layout**: Automatically adapts to different screen sizes
- **Interactive Lightbox**: Click any artwork to view in high resolution with navigation
- **Hover Effects**: Smooth animations and overlay information on hover
- **Keyboard Accessible**: Full keyboard navigation support
- **SEO Optimized**: Proper meta tags and structured data
- **Performance Focused**: Lazy loading, optimized images, and minimal JavaScript

## About the Collection

This collection features a diverse range of digital artwork including:
- Character illustrations and portraits
- Nature studies and landscapes  
- Abstract compositions and experiments
- Fantasy and sci-fi themed pieces

Each piece is numbered and cataloged for easy reference. The gallery supports various image formats (PNG, JPG, JPEG) and automatically generates optimized thumbnails.

## Technical Stack

- **Jekyll**: Static site generator
- **GitHub Pages**: Hosting platform
- **Cayman Theme**: Base theme with extensive customizations
- **CSS Grid**: Modern layout system
- **Vanilla JavaScript**: Lightweight interactivity
- **WebP/AVIF Support**: Modern image formats with fallbacks

## Development

To run locally:

```bash
bundle install
bundle exec jekyll serve
```
